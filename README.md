# Grade 8 Science MCQ Quiz: Magnetism, Dynamics & Sound

Interactive quiz with 80 multiple-choice questions covering:

- **Magnetism** (including electromagnets)
- **Dynamics** (Force & Motion / Exploring Forces)
- **Sound**

## Features
- 60-second timer per question
- Instant feedback on answers
- Score tracking
- Topic badges
- Progress bar
- Responsive design

## How to use
Open `index.html` in a browser or visit the GitHub Pages site.

**GitHub Pages URL:** https://jitendraphand.github.io/Magnetism/

To enable Pages (if not already):
1. Go to repository Settings → Pages
2. Source: Deploy from a branch → main → / (root)
3. Save

Questions are based on standard Class 8 Science (CBSE/NCERT aligned) topics.
